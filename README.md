# Shivraj Enterprises — Website

This is the frontend application for the Shivraj Enterprises product catalog. See the [project README](../README.md) for full documentation.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Catalog files

| File | Purpose |
|------|---------|
| `src/data/products.config.ts` | Product definitions |
| `src/data/categories.config.ts` | Categories and product assignments |
| `src/data/catalog.ts` | Joined catalog and search/filter helpers |
| `public/images/` | Product photos |
